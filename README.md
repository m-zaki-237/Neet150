## How to Practice Each Problem

1. Understand the problem.
2. Identify the underlying pattern.
3. Solve it yourself for 20–30 minutes.
4. Think through the brute-force solution mentally.
5. Find the optimized approach.
6. Implement it without looking at the solution.
7. Analyze time and space complexity.
8. Re-solve the problem after a few days without assistance.
9. Keep a short note about the pattern/trick used.
